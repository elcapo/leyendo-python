# Leyendo Python

## Aplicaciones con interfaces gráficas

Programas de usuario final escritos en Python. Muestran cómo se combinan librerías, integraciones con el sistema y decisiones de diseño en un producto completo.

### CLI y TUI

| Proyecto | GitHub | Documentación | Descripción |
| --- | --- | --- | --- |
| Cookiecutter | [GitHub](https://github.com/cookiecutter/cookiecutter) | [Docs](https://cookiecutter.readthedocs.io/) | Generación de proyectos desde plantillas; diseño simple y extensible. |
| Datasette | [GitHub](https://github.com/simonw/datasette) | [Docs](https://docs.datasette.io/) | Publica SQLite como API y web explorable; ejemplo claro de herramienta con plugins. |
| Glances | [GitHub](https://github.com/nicolargo/glances) | [Docs](https://glances.readthedocs.io/) | Monitor de sistema multiplataforma con arquitectura de plugins. |
| Harlequin | [GitHub](https://github.com/tconbeer/harlequin) | [Docs](https://harlequin.sh/) | Cliente de base de datos para la terminal. |
| HTTPie | [GitHub](https://github.com/httpie/cli) | [Docs](https://httpie.io/docs/cli) | Cliente HTTP para la terminal con salida formateada y gran UX. |
| MkDocs | [GitHub](https://github.com/mkdocs/mkdocs) | [Docs](https://www.mkdocs.org/) | Generador de documentación con sistema de plugins muy limpio. |
| pipx | [GitHub](https://github.com/pypa/pipx) | [Docs](https://pipx.pypa.io/) | Instalador de aplicaciones Python en entornos aislados. |
| Posting | [GitHub](https://github.com/darrenburns/posting) | [Docs](https://posting.sh/) | Cliente API que vive en la terminal. |
| pre-commit | [GitHub](https://github.com/pre-commit/pre-commit) | [Docs](https://pre-commit.com/) | Framework para gestionar git hooks en múltiples lenguajes. |
| Sphinx | [GitHub](https://github.com/sphinx-doc/sphinx) | [Docs](https://www.sphinx-doc.org/) | Generador de documentación estándar del ecosistema Python. |

### GUI de escritorio

| Proyecto | GitHub | Documentación | Descripción |
| --- | --- | --- | --- |
